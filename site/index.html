Hazzel

Tiny, open, approval-first coding agent.

Hazzel is a coding agent harness and CLI that lives in your terminal. It reads code, edits files, runs commands, and works with git — always with your approval first.

Its output is closer to a Unix shell than an IDE in the terminal: every step is visible, every mutation goes through you.

It is open source (AGPL-3.0), model-agnostic, and runs on macOS, Linux, and Windows.

Install

$ pip install hazzel

Supports macOS, Linux, and Windows on Python ≥ 3.10. Run /model, pick a provider, paste your key.

Why Hazzel

  • Approval-first: file changes show a diff before they apply, shell commands ask first, destructive git stays blocked.
  • Small and inspectable: no background agents, no deploys, no hidden behavior — a terminal agent you can see through.
  • Senior review built in: /review returns a verdict plus severity-ranked findings, scoped to a file or the whole codebase.
  • Goal-driven: /goal pins an objective and every turn steers toward it until done.
  • Token-efficient: web pages condense to query-relevant sentences, history compacts between turns.
  • Model and provider agnostic: Groq, OpenAI, Anthropic, Mistral, Gemini, DeepSeek, OpenRouter, and local Ollama through one key each.

Commands

Session

  • /model — switch provider and model
  • /goal [@objective] — pin an objective, /goal run executes it
  • /plan on|off — read-only exploration with a numbered plan
  • /prove on|off — smoke-check edits before you trust them
  • /usage — token spend this session
  • /clear — reset the conversation
  • /logout — wipe saved keys

Git

  • /status — working-tree status
  • /diff [--staged] — changed files with a full-diff browser
  • /review [@file|codebase] — senior-level review with fixes
  • /commit [message] — drafted message, y/e/n approval
  • /branch — list, create, switch
  • /log [n] — recent commits
  • /push /pull /sync — remote sync, never --force

Pull requests

  • /pr — list open PRs
  • /pr view|diff|checks <n> — read a PR
  • /pr comment|merge|close <n> — act on a PR, approval first
  • /pr create <title> — open a PR

Transcript

  • /summary — what the last turn did
  • /export [file] — save the transcript to markdown
  • /copy [code] — copy the last reply
  • /retry — re-run your last message
  • /undo [n] — revert file changes
  • /init [file] — generate an AGENTS.md project map
  • /docs — the full usage guide, in your terminal
