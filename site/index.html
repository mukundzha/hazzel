Hazzel

A small terminal coding agent. Bring your own key.

Hazzel lives in your terminal. It reads code, edits files, runs commands, and works with git — always with your approval first.

pip install hazzel

v1.3.0 · open source · no subscription

Why Hazzel?

Most coding agents keep getting bigger. Hazzel stays small on purpose.

The model suggests what to do. Hazzel decides whether and how to do it. Every mutation goes through you: file changes show a diff before they apply, shell commands ask first, and destructive git stays blocked.

If you want the most feature-heavy agent, there are better options. If you want a terminal agent you can see through, that's Hazzel.

❯ Fix the failing test in tests/test_agent.py

● read_file tests/test_agent.py

● edit_file src/hazzel/agent.py — diff shown, you approve

● run_command pytest -q — passed

The loop

  1. Ask in plain words — "fix the failing test", "explain this file", "review my diff".
  2. Approve each step — edits show a diff first, commands ask first. Nothing mutates without you.
  3. Verify together — Hazzel runs the check and reports back. Pipe the rest of your day through it.

What it does

  • Reads your codebase — search, list, and read across the project. Tag files with @path to pin them into context; plan mode explores read-only and hands you a numbered plan.
  • Edits with approval — every change shows a diff before it applies, /undo reverts anything, and shell commands run sandboxed in your project root.
  • Reviews like a senior — /review returns a verdict plus severity-ranked findings with file:line fixes; /review @file scopes to one file, /review codebase to everything.
  • Git-native — status, diff browser, suggested commit messages, push/pull/sync, and GitHub PRs through gh. Destructive git (--force, reset --hard) stays blocked.

Providers

Groq, OpenAI, Anthropic, Mistral, Gemini, DeepSeek, OpenRouter, Ollama. Bring your own key, switch with /model.
